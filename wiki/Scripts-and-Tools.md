# السكربتات والأدوات

## سكربتات Python
- `battery_info.py` معلومات البطارية.
- `devices_temp.py` درجات حرارة الأجهزة.
- `top_cpu_usage.py` أعلى عمليات CPU.
- `top_ram_usage.py` أعلى عمليات RAM.
- `scan_wallpapers.py` فحص الخلفيات.
- `m3/dynamic-m3.py` توليد ألوان ديناميكي.
- `create_depth_image_rembg.py` إنشاء طبقة عمق بـ rembg.
- `create_depth_image_opencv.py` إنشاء طبقة عمق بـ OpenCV.
- `overlay_cache_images_cleaner.py` تنظيف كاش العمق.
- `network/list_wifi.py` مسح الشبكات.
- `network/connect_wifi.py` اتصال بالشبكة.
- `network/data_usage.py` استهلاك البيانات.
- `network/live_usage.py` سرعة لحظية.
- `ai/main.py` تشغيل بوابة الذكاء الاصطناعي.
- `ai/list-gemini.py` جلب نماذج Gemini.
- `get_clipboard.py` إدارة الحافظة.

## سكربتات Bash
- `cpu_usage.sh` قراءة CPU.
- `ram_usage.sh` قراءة RAM.
- `internet.sh` سرعة الشبكة.
- `temp.sh` حرارة الأجهزة.
- `playerctl.sh` التحكم بالميديا.

## ملاحظة
هذه السكربتات تُستدعى عبر `App.qml` لتوحيد المسارات والأوامر.

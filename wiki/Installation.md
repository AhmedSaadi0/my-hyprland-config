# التثبيت

## التثبيت التلقائي
```bash
git clone --depth 1 https://github.com/AhmedSaadi0/NibrasShell.git
cd NibrasShell
python install.py
```

## ما يقوم به السكربت
- تثبيت المتطلبات الأساسية.
- نسخ ملفات الواجهة.
- إنشاء ملف الإعدادات `~/.nibrasshell.json`.
- تحديث ملفات Quickshell.
- إزالة الواجهة عند الحاجة.

## التوزيعات المدعومة في السكربت
- Arch
- Fedora
- Void

# القائمة الجانبية

## الشريط الجانبي
- أيقونات منظّمة إلى مجموعات.
- يدعم نمط Floating أو Docked.
- يحرّك محتوى سطح المكتب حسب نمط القائمة.

## محتوى القائمة الجانبية
- Dashboard.
- Notifications.
- Weather.
- Monitoring.
- Network.
- Clipboard.
- Todo.
- Translator.
- AI Bot.
- App Launcher.

## Dashboard
- تبديل الثيمات بسرعة.
- التحكم بوضع الطاقة.

## Monitoring
- مؤشرات CPU و RAM و الحرارة والبطارية.
- جداول أعلى العمليات.
- سجل أحداث Spike Analysis عبر الذكاء الاصطناعي.

## Network
- مسح الشبكات بشكل دوري.
- اتصال وفصل ونسيان.
- استهلاك بيانات يومي وشهري.

## Todo
- مهام مع تواريخ وأولوية وحالة إكمال.
- ترتيب تلقائي حسب الأهمية.

## Clipboard
- قائمة الحافظة.
- تفعيل أو حذف أو مسح.

NibrasShell
Hyprland + Quickshell
الرئيسية المميزات الصور التثبيت الوثائق المطورون التغييرات خارطة الطريق الأسئلة

الوثائق

اختصر طريقك إلى التفاصيل التقنية.

الواجهة

  • الشريط العلوي
  • القائمة الجانبية
  • الكبسولة الذكية
  • سطح المكتب والخلفيات

الخدمات

  • SystemService
  • Weather
  • MusicService
  • ClipboardService

الإعدادات

  • ملف الإعدادات `~/.nibrasshell.json`
  • لوحة الإعدادات الداخلية
  • الثيمات والألوان

المطورون

  • سكربتات Python و Bash
  • نظام الخلفيات
  • تأثيرات العمق والبلور

توثيق المطورين

انتقل إلى صفحة المطورين لمعرفة المعمارية والخدمات والسكربتات بالتفصيل.

وثائق المطورين
هذه الصفحة مختصرة، بينما التفاصيل الكاملة في الويكي.

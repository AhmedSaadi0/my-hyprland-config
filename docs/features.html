المميزات

نظرة تفصيلية لأهم ما يميز الواجهة.

الكبسولة الذكية

عرض موجز للطقس والميديا مع توسعة تفاعلية وطبقة AI.

القائمة الجانبية

تنقّل سريع بين الأقسام مع نمط عائم أو ثابت.

مراقبة النظام

CPU و RAM و الحرارة والبطارية مع تحليل ارتفاعات مفاجئة.

الطقس الذكي

تحليل ذكي وتنبيهات جوية مع تحديثات مرنة حسب الحالة.

الثيمات والخلفيات

ثيمات جاهزة مع دعم خلفيات ديناميكية وتوليد ألوان تلقائي.

لوحة إعدادات احترافية

تحكم كامل بالواجهة والموارد والذكاء الاصطناعي.

قائمة مختصرة بالمزايا

  • شريط علوي غني بعناصر النظام ومساحات العمل.
  • مشغل تطبيقات جانبي وسفلي.
  • إشعارات فورية ومركز إشعارات.
  • تأثير عمق للساعة مع Overlay.
  • تكامل مع Pipewire و MPRIS و wl-clipboard.
